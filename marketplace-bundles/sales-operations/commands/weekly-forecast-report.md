# Weekly Forecast Report

Generates comprehensive weekly revenue forecast reports for leadership and board communications.

## Features

- Weekly pipeline-based revenue forecast
- Comparison to previous week's forecast
- Accuracy tracking against actuals
- Top deal highlighting
- Scenario analysis (best/expected/worst)
- Risk and opportunity summaries
- Stage conversion trend analysis
- Automated distribution to stakeholders

## Usage

Generate a weekly forecast summary:

```
/weekly-forecast-report
```

Or with specific focus:

```
/weekly-forecast-report Focus on enterprise deals >$100k
/weekly-forecast-report Include product segment breakdown
```

## Output

Generates:
- Executive summary with key metrics
- Detailed pipeline forecast by stage
- Top 10 deals at risk or accelerating
- Quarterly outlook
- Previous week variance analysis
- Recommended actions

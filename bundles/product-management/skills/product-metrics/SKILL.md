# Product Metrics

Define what success looks like before building, then measure whether the work
actually moved the needle.

## Capabilities

- Define a North Star metric and its supporting input metrics
- Map the activation and AARRR funnel (acquisition, activation, retention, referral, revenue)
- Separate leading indicators from lagging outcomes
- Set baselines, targets, and guardrail metrics for each initiative
- Design event tracking plans engineers can implement
- Frame and reason about A/B tests and their readouts
- Avoid vanity metrics and detect metric gaming
- Build dashboards tying features to outcomes

## Usage

This skill attaches a measurable success definition to product work and
designs the instrumentation needed to evaluate it honestly.

## Features

- North Star and input-metric definition
- AARRR / activation funnel mapping
- Leading vs. lagging indicator framing
- Baseline, target, and guardrail setting
- Event tracking plan templates
- Experiment design and readout structure
- Retention and cohort analysis framing
- Vanity-metric and gaming checks

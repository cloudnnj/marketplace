# Roadmap Prioritization

Turn a noisy backlog into a defensible, sequenced roadmap using transparent
scoring instead of the loudest opinion in the room.

## Capabilities

- Score initiatives with RICE (Reach, Impact, Confidence, Effort)
- Apply ICE, value-vs-effort, WSJF, and MoSCoW where they fit better
- Classify features with the Kano model (basic, performance, delighter)
- Make trade-offs explicit and record assumptions behind each score
- Sequence work into now / next / later horizons
- Map every roadmap item to a business goal and success metric
- Surface dependencies, risks, and the bet each item represents
- Communicate the roadmap to engineering and stakeholders

## Usage

This skill prioritizes a list of features or initiatives and produces a
sequenced, goal-aligned roadmap with the reasoning made visible.

## Features

- RICE / ICE / WSJF scoring tables
- Value-vs-effort 2x2 quadrant mapping
- Kano and MoSCoW classification
- Now/next/later roadmap formatting
- Goal-to-feature traceability matrix
- Capacity-aware sequencing
- Assumption and confidence tracking
- Stakeholder-ready roadmap summaries

# Discovery and Validation

Structured customer discovery so the team invests in problems worth solving
before writing code.

## Capabilities

- Frame the riskiest assumption behind a product idea
- Design non-leading, behavior-anchored interview guides
- Apply the Jobs-to-be-Done lens to uncover real motivations
- Run lightweight validation experiments (landing page, concierge, fake door, prototype)
- Distinguish must-have problems from nice-to-have requests
- Score opportunities on value, feasibility, and viability
- Synthesize qualitative signal into prioritizable problem statements
- Build an evidence trail that justifies (or kills) a roadmap bet

## Usage

This skill guides the team through discovery: from a vague idea to a
validated, evidence-backed problem statement ready for prioritization.

## Features

- Assumption mapping and riskiest-assumption tests
- Interview guide templates (open, past-behavior questions)
- Jobs-to-be-Done synthesis (job, pain, gain, frequency, intensity)
- Validation experiment playbook with success thresholds
- Opportunity Solution Tree structuring
- Problem-statement templates with confidence levels
- Build / measure / learn loop scaffolding
- Anti-pattern checks (leading questions, sample bias, vanity validation)

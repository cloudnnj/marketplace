# Accessibility Test Automation

Automated accessibility testing and WCAG compliance verification for React components.

## Capabilities

- Run axe-core accessibility audits on components
- Check WCAG 2.1 AA compliance automatically
- Detect missing ARIA labels and landmarks
- Verify keyboard navigation support
- Test color contrast ratios
- Generate accessibility reports
- Integrate with CI/CD pipelines

## Usage

This skill provides automated accessibility testing for React components and pages.

## Features

- Accessibility audit integration via axe-core
- WCAG compliance checking
- Keyboard navigation testing
- Screen reader compatibility verification
- Contrast ratio validation
- Automated report generation
